# Changelog

* **v2.0.1**: 
Added new documentation files to the repository (e.g., the `CITATION.cff` file) and refactored some components (e.g., `main.py` changed into `validate.py`).
* **v2.0.0**:
Added new documentation, including annotation properties (e.g., `bibo:doi`, `schema:codeRepository`, etc.), term properties (e.g., `vann:example`, `vs:term_status`, etc.), exemplary competency questions with their respective SPARQL queries, and a Grafoo diagram.
Added classes and properties, reused from existing ontologies (e.g., `foaf:Person`, `dcterms:creator`, etc.) and previously only documented in a separate document for mapping the DataCite metadata schema properties to the DataCite Ontology patterns.
